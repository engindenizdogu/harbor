> A dual-agent orchestration platform enabling users to generate, share, and deploy functional applications from natural language prompts in under 2 minutes.

## Quick Facts
- **Context:** Radiothon 2026 (24 Hour Hackathon, January 2026)
- **Tech Stack:** React Native, FastAPI, Claude SDK, Supabase, Daytona
- **Links:** [GitHub Repo](https://github.com/engindenizdogu/vibe-feed)

## Overview and Problem
The goal of this hackathon project was to drastically lower the barrier to software creation by building a social discovery platform where users can instantly prompt and deploy working applications.

## What I Built
- **Engineered** a full-stack social discovery platform using React Native and a FastAPI backend.
- **Implemented** Daytona containerized sandboxes for isolated code execution and automated deployment.
- **Integrated** Supabase authentication for secure user sessions.
- **Designed** a dual-agent orchestration system using the Claude Agent SDK for real-time collaborative app generation.

## Key Results and Impact
- Delivered a functional prototype within a 24-hour hackathon time limit.
- Accelerated the app creation lifecycle, allowing full natural language to deployment in under 2 minutes.
